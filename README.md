# Berichten API Plugin

This Berichten API plugin is used to create berichten (messages) in the VNG service
[Open-VTB](https://github.com/maykinmedia/open-vtb).

## Getting started

1. Have an [Open-VTB](https://github.com/maykinmedia/open-vtb) instance available and note its API URL and token
2. Add the plugin to your GZAC/Valtimo application and configure it with the Open-VTB API URL and token
3. Use the `create-bericht` action in a process to register berichten

To try it out locally with the bundled example application, follow the
[Example Application](documentation/berichten-api.md) guide. For plugin development, see
[Getting Started](documentation/getting-started.md).
